Local-first, SSD-backed desktop runtime for frontier-scale AI models.

## Quick Start

```bash
cargo build --release --bin edgeforge
./target/release/edgeforge serve
```

## Architecture

11-layer architecture with 19 crates, 32 ADRs, 16 SQL migrations.
See `docs/` for details.
