## Architecture Overview

The MAPE-K loop runs the Monitor → Analyze → Plan → Execute cycle over a
shared Knowledge base:

```
┌─────────────────────────────────────────────────────────────┐
│                    MAPE-K Autonomic Loop                     │
│                                                              │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌────────┐ │
│  │ Monitor  │───▶│ Analyze  │───▶│  Plan    │───▶│Execute │ │
│  │          │    │          │    │          │    │        │ │
│  │ Drain    │    │ SPC      │    │ Select   │    │ Mutate │ │
│  │ events   │    │ classify │    │ remed.   │    │ ctx    │ │
│  └──────────┘    └──────────┘    └──────────┘    └────┬───┘ │
│       │               │               │              │     │
│       ▼               ▼               ▼              ▼     │
│  ┌──────────────────────────────────────────────────────┐  │
│  │              Knowledge Base (shared)                  │  │
│  │  • Events (bounded to 10,000)                        │  │
│  │  • Failure patterns (5 kinds)                        │  │
│  │  • Autonomic actions (audit log)                     │  │
│  │  • Test generator (antifragile)                      │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### MAPE Phases

| Phase | What it does |
|---|---|
| **Monitor** | Drains a batch of `ControlEvent`s from the event channel |
| **Analyze** | Classifies each event's metric via SPC (Welford's algorithm). Common-cause (within 3σ) vs special-cause (beyond 3σ) |
| **Plan** | Finds the highest-severity failure pattern and maps it to a remediation |
| **Execute** | Applies the remediation against `RemediationContext` (mutates real state) |
| **Knowledge** | Records the action; if the remediation succeeded, generates a regression test |

### Antifragile Property

When a remediation succeeds, `TestGenerator::generate()` produces a real
Rust test file encoding the failure condition. The test is added to the CI
suite so the same failure can never silently regress — **the system becomes
stronger because it failed**.

## Quick Start: Run a MAPE-K Cycle

```rust
use edgeforge_autonomic::*;
use edgeforge_core::{ControlEvent, ControlEventKind};
use std::sync::Arc;
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    // 1. Create the event channel.
    let (tx, rx) = mpsc::channel(256);

    // 2. Inject a thermal throttle event.
    tx.send(ControlEvent {
        timestamp_ms: 0,
        kind: ControlEventKind::ThermalSample {
            temp_celsius: 75.0,
            throttled: true,
            paused: false,
        },
    }).await.unwrap();

    // 3. Set up the MAPE-K loop.
    let knowledge = Arc::new(AutonomicKnowledge::new());
    let test_gen = TestGenerator::new();
    let ctx = Arc::new(RemediationContext::new());
    let mape = MapeKLoop::new(
        MapeKConfig::default(),
        rx,
        knowledge.clone(),
        test_gen,
        ctx.clone(),
    );

    // 4. Run one cycle.
    if let Some((remediation, result, gen_test)) = mape.cycle_once().await {
        println!("Remediation: {:?}", remediation.kind());
        println!("Result: {:?}", result);
        println!("Context: prefetch_depth={}", ctx.prefetch_depth());

        if let Some(test) = gen_test {
            println!("Generated test: {} → {}", test.name, test.target_path);
            println!("Source:\n{}", test.source);
        }
    }
}
```

Output:
```
Remediation: ReducePrefetchDepth
Result: Success { detail: "Prefetch depth reduced to 3 (was 4)" }
Context: prefetch_depth=3
Generated test: test_thermal_throttle_remmediation → tests/e2e/autonomic/test_thermal_throttle.rs
Source:
//! Antifragile regression test — auto-generated by the MAPE-K loop.
//! Failure kind: ThermalThrottle
//! ...
```

## Failure Pattern Detection

`AutonomicKnowledge::detect_patterns()` examines SPC classifications + the
event stream to identify 5 failure kinds:

| Failure Kind | Trigger | Severity |
|---|---|---|
| `ThermalThrottle` | `ssd_temp_c ≥ 70°C` (SpecialCause) OR `ThermalSample { throttled: true }` | 5 + occurrences |
| `PeerDisconnect` | `PeerLost` event OR `peer_rtt_ms > 500` (SpecialCause) | 3 + occurrences |
| `CorruptExpert` | `io_latency_us > 10,000` (SpecialCause) | 4 + occurrences |
| `SpeculationMissSpike` | ≥3 consecutive `SpeculationVerdict { hit: false }` | 2 + occurrences |
| `VerificationFailure` | `VerificationVerdict { outcome: Failed }` | 4 + occurrences |

### SPC Classification (Welford's Algorithm)

The Analyze phase uses Welford's online algorithm to compute a rolling mean
+ variance for each metric. A value is classified as:

- **Common-cause** — within 3σ of the rolling mean (systemic variation)
- **Special-cause** — beyond 3σ (one-off, requires targeted fix)

Requires ≥30 samples before classification is meaningful (below that, all
values are classified as SpecialCause).

## Remediation Actions

Each remediation mutates real state in `RemediationContext`:

| Remediation | State Mutation | Success Condition | Skipped Condition |
|---|---|---|---|
| `ReducePrefetchDepth` | `prefetch_depth -= 1` | `prefetch_depth > 0` | `prefetch_depth == 0` |
| `EvictPeer` | `evicted_peers.insert(peer)` | Newly evicted | Already evicted |
| `EvictExpert` | `evicted_experts.insert(expert)` | Newly evicted | Already evicted |
| `ReduceDraftMax` | `draft_max: 16→8→4→2` | `draft_max > 2` | `draft_max <= 2` |
| `TriggerKaniReverification` | `kani_queue.push(target)` | Always succeeds | — |
| `ReroutePeer` | `rerouted_peers.insert(peer)` | Always succeeds | — |

### Failure → Remediation Mapping

The Plan phase maps each failure kind to a remediation:

| Failure Kind | Remediation |
|---|---|
| `ThermalThrottle` | `ReducePrefetchDepth` |
| `CorruptExpert` | `EvictExpert` (with the pattern's target) |
| `PeerDisconnect` | `EvictPeer` (with the pattern's target) |
| `SpeculationMissSpike` | `ReduceDraftMax` |
| `VerificationFailure` | `TriggerKaniReverification` (with the pattern's target) |

## Antifragile Test Generation

When a remediation succeeds, `TestGenerator::generate()` produces a
`GeneratedTest` with real Rust source code:

| Failure Kind | Test Type | Target Path |
|---|---|---|
| `ThermalThrottle` | `RegressionTest` | `tests/e2e/autonomic/test_thermal_throttle.rs` |
| `CorruptExpert` | `RegressionTest` | `tests/e2e/autonomic/test_corrupt_expert.rs` |
| `PeerDisconnect` | `RegressionTest` | `tests/e2e/autonomic/test_peer_disconnect.rs` |
| `SpeculationMissSpike` | `RegressionTest` | `tests/e2e/autonomic/test_speculation_miss.rs` |
| `VerificationFailure` | `KaniHarness` | `tests/kani/kani_verification_failure.rs` |

The generated test:
1. Sets up the failure condition (e.g. inject a high-temperature event)
2. Runs the remediation against a fresh `RemediationContext`
3. Asserts the remediation succeeded and mutated state
4. Includes edge-case tests (e.g. skipped at minimum depth)

### Committing Generated Tests

By default, `MapeKConfig::commit_generated_tests` is `false` — tests are
returned by `cycle_once()` but not written to disk. To write them to the
repo:

```rust
if let Some((_, _, Some(test))) = mape.cycle_once().await {
    std::fs::create_dir_all(std::path::Path::new(&test.target_path).parent().unwrap())?;
    std::fs::write(&test.target_path, &test.source)?;
    println!("Committed: {}", test.target_path);
}
```

## API Reference

### `MapeKLoop`

| Method | Returns | Purpose |
|---|---|---|
| `new(config, events_rx, knowledge, test_gen, ctx)` | `Self` | Create the loop |
| `cycle_once()` | `Option<(Remediation, RemediationResult, Option<GeneratedTest>)>` | Run one MAPE cycle |
| `remediation_context()` | `&Arc<RemediationContext>` | Get the context |
| `knowledge()` | `&Arc<AutonomicKnowledge>` | Get the knowledge base |

### `RemediationContext`

| Method | Returns | Purpose |
|---|---|---|
| `new()` | `Self` | Create with defaults (prefetch_depth=4, draft_max=16) |
| `with_initial_state(prefetch_depth, draft_max)` | `Self` | Create with custom initial state |
| `prefetch_depth()` | `u32` | Current prefetch depth |
| `draft_max()` | `u32` | Current draft-max |
| `is_peer_evicted(peer)` | `bool` | Check if a peer is evicted |
| `is_expert_evicted(expert)` | `bool` | Check if an expert is evicted |
| `is_peer_rerouted(peer)` | `bool` | Check if a peer is rerouted |
| `kani_queue_len()` | `usize` | Kani re-verification queue depth |
| `snapshot()` | `RemediationContextSnapshot` | Get a snapshot of all state |

### `AutonomicKnowledge`

| Method | Returns | Purpose |
|---|---|---|
| `new()` | `Self` | Create empty knowledge base |
| `record_event(event)` | `()` | Store a ControlEvent (bounded to 10,000) |
| `detect_patterns(classifications)` | `Vec<FailurePattern>` | Detect failure patterns |
| `record_action(action)` | `()` | Store an autonomic action (bounded to 10,000) |
| `actions()` | `Vec<AutonomicAction>` | Get all recorded actions |
| `event_count()` | `usize` | Number of stored events |
| `pattern_count()` | `usize` | Number of detected patterns |
| `clear()` | `()` | Clear all state (for testing) |

### `TestGenerator`

| Method | Returns | Purpose |
|---|---|---|
| `new()` | `Arc<Self>` | Create the generator |
| `generate(patterns, remediation)` | `Option<GeneratedTest>` | Generate a regression test |

## Troubleshooting

### "Remediation::execute() returns hardcoded Success"

This was a **Phase 20 bug**. It is fixed: `execute()` now takes a
`&RemediationContext` and mutates real state. Update to the latest build:

```bash
cargo build --release -p edgeforge-autonomic
```

### "TestGenerator::generate() returns None"

This was a **Phase 20 bug**. It is fixed: `generate()` now produces real
Rust test source code when a pattern matches. It still returns `None` when
`patterns` is empty — that's correct behavior.

### "Knowledge::detect_patterns() returns Vec::new()"

This was a **Phase 20 bug**. It is fixed: `detect_patterns()` now examines
SPC classifications + events to detect 5 failure kinds. It still returns
`Vec::new()` when no patterns are detected — that's correct behavior.

### "cycle_once() returns None"

This happens when:
1. No events were drained from the channel (empty channel), OR
2. Events were processed but no failure patterns were detected

Check that you're sending events that trigger a pattern (see
[Failure Pattern Detection](#failure-pattern-detection)).

### "Remediation returns Skipped"

This is correct behavior when the remediation can't be applied:
- `ReducePrefetchDepth` at depth 0 → Skipped
- `EvictPeer` for an already-evicted peer → Skipped
- `EvictExpert` for an already-evicted expert → Skipped
- `ReduceDraftMax` at draft_max=2 → Skipped

Skipped remediations don't generate regression tests (the failure condition
was already handled).

### "SPC classifies everything as SpecialCause"

SPC requires ≥30 samples before classification is meaningful. Below 30
samples, all values are classified as SpecialCause. Send more events to
build up the rolling stats.
